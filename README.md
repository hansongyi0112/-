개인정보와 운영 원칙
이 앱은 어디에도 데이터를 자체 저장하지 않습니다. 답변은 화면에만 존재하며, 사용자가 복사하거나 전송 버튼을 누른 경우에만 상담자의 시트로 이동합니다.
생년월일시는 민감한 개인정보입니다. 연동된 구글 시트는 비공개(나만 보기) 로 유지하고, 상담 종료 후 삭제 요청이 있으면 지체 없이 지우는 것을 원칙으로 합니다.
동의 화면에 명시된 대로, 명리 해석은 기질과 흐름을 읽는 참고 자료이며 미래를 확정하지 않습니다. 진로 결정은 표준 진로검사·상담과 함께 종합하여 본인이 내립니다.
미성년자를 대상으로 운영할 때는 보호자 안내와 동의를 함께 받는 것을 권장합니다.
